# 부동산 양도세 계산기

블로그 링크용 정적 웹 계산기입니다. index.html을 GitHub Pages로 배포합니다.

## 현재 기능
- 취득/양도일과 거주 구간 날짜 입력
- 윤일 반영, 중복 구간 병합, 취득 전·양도 후 날짜 제외
- 불연속 구간은 참고 일수 자동 합산, 세법상 인정 연수 확인값 입력 전 세액 계산 보류

## 적용 범위
참고용 추정치입니다. 불연속 거주기간의 세법상 연수 환산은 공식 세부 산식 검증이 완료되지 않았습니다. 모든 세율·특례를 검증한 신고용 프로그램이 아닙니다. 상세 내용은 검토기록.md를 확인하세요.

금액과 날짜는 브라우저에서 계산하며 서버로 전송하지 않습니다. 웹폰트는 Google Fonts에서 불러옵니다.

## 검증
`node verify.cjs`

## 배포
GitHub Settings → Pages → Deploy from a branch → main / (root).
